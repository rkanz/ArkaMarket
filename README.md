# Persian Clothing Store

A simple e-commerce website built with Django as a portfolio project.

The goal of this project was to practice building a complete web application with user authentication, database relationships, product management, and common e-commerce features such as favorites, ratings, filtering, and shopping carts.

## Features

### User Accounts

* Register, login, and logout
* Edit profile information
* Protected pages accessible only to authenticated users

### Products

* Browse products
* View detailed product information
* Rate products using a star rating system
* Featured products and categories on the homepage

### Shopping Experience

* Add and remove products from the cart
* Automatic cart total calculation
* Add products to favorites
* View and manage favorite products

### Filtering & Sorting

Products can be filtered by:

* Category
* Brand
* Gender

Products can be sorted by:

* Price
* Rating
* Date added

### Contact Page

Users can send messages to the site administrator through a contact form.
